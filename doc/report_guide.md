
# `report.md`形式におけるレポート作成ガイド

## 基本的なMarkdown書式

### 見出し
- 見出しは `#`、`##`、`###` などを使用して作成します。
- 例:
  - 見出し1: `# 見出し1`
  - 見出し2: `## 見出し2`
  - 見出し3: `### 見出し3`

### リスト
- 箇条書きリストは `-` または `*` を使用します。
- 例: 
  ```
  - リストアイテム1
  - リストアイテム2
  ```
- 番号付きリストは `1.`、`2.` などを使用します。
- 例: 
  ```
  1. 最初のアイテム
  2. 次のアイテム
  ```

### 強調
- 太字は `**テキスト**` で、斜体は `*テキスト*` で表現します。
- 例: 
  - 太字: `**太字**`
  - 斜体: `*斜体*`

### リンク
- リンクは `[表示テキスト](URL)` の形式で挿入します。
- 例: `[Google](https://www.google.com)`

### 画像
- 画像は `![キャプション](画像のパス)` の形式で挿入します。
- 例: `![サンプル画像](path/to/image.jpg)`

## TeX変換時の特別な書式

### LaTeXコマンドの埋め込み
- LaTeXコマンドは `<!-- LaTeX コマンド -->` の形式でMarkdown文書に埋め込みます。

### PDFの挿入
- PDFは `@import "ファイルパス.pdf"` の形式で挿入します。
- `\setpdfn` と `\setpdfm` を使用してPDFの表示方法を制御します。

- このページにヘッダーやフッターを表示しないようにするには、`<!-- LaTeX 	hispagestyle{empty} -->` を使用します。

## 追加情報

### 画像について
- 画像を挿入すると、「図」として自動的に図番号が付与されます。
- 画像のキャプションは画像の下に表示されます。
- 例: `![キャプション](画像のパス)`

### PDFの挿入について
- 挿入するPDFが1ページの場合、`<!-- LaTeX \setpdfm{1} -->` を使用します。
- 複数ページのPDFを挿入する場合は、`<!-- LaTeX \setpdfm{1} -->` に続いて `<!-- LaTeX \setpdfn{2} -->` を記述します。

# `makefile`によるPDF作成ガイド

`makefile`を使用してレポートのPDFを生成する際の主要なポイントを以下に説明します。

## OBJS変数による依存ファイルの指定
- `OBJS`変数には、レポート作成に必要な依存ファイルを指定します。
- 例:
  ```
  OBJS = \
         $(SP)/specificationV1.pdf \
         $(DT)/mode4.png $(DT)/mode4graph.png $(DT)/mode4gosa.png\
         src/led.c.pdf src/led.h.pdf src/h8sample.c.pdf
  ```

## xxPAD.pdfの生成
- `xxPAD.pdf`は`c2pad`コマンドによって`xx.c`ファイルから生成されます。
- `makefile`内のルール:
  ```
  %PAD.pdf: %.c
  	c2pad $*
  ```

## xx.c.pdfの生成
- `xx.c.pdf`は`$(LISTPDF)`コマンドによって`xx.c`ファイルから生成されます。
- `makefile`内のルール:
  ```
  %.c.pdf: %.c
  	$(LISTPDF) $<
  ```

## 部分的な生成のオプション
- `make`コマンドにオプションを付けることで、特定の部分だけを生成することができます。
- 例:
  - `make PDF`：PDFファイルのみを生成します。
  - `make TeX`：TeXファイルのみを生成します。

## レポート作成の具体的な手順

レポートを作成する際の具体的な手順を以下に示します。

1. **仕様書のPDFファイル名確認**:
   - 仕様書のPDFファイル名を確認します。

2. **ソースコードファイルの確認**:
   - `.c` および `.h` ファイルのファイル名を確認します。

3. **実験データの画像ファイル保存**:
   - 実験データを画像ファイルとして保存し、ファイル名を確認します。

4. **makefileへの依存関係反映**:
   - `makefile`に必要な依存関係を反映します。

5. **report.mdの執筆**:
   - `report.md`の本文を執筆し、適切に画像ファイルやPDFファイルを引用、挿入します。

6. **Markdownプレビューの使用**:
   - `report.md`のMarkdownプレビューは概形の確認にのみ使用します。

7. **makeコマンドでの最終確認**:
   - 最終的な文書は`make`コマンドを実行して`report.pdf`を生成し、それを確認します。
