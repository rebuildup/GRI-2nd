# 製品 V2 仕様書 担当別レビュー票

## 1. このレビュー票の使い方

このレビュー票は、製品 V2 仕様書を担当ごとに確認するためのものである。

各担当者は、自分の担当欄にある確認項目を読み、修正が終わった項目のチェック欄を`[ ]`から`[x]`へ変更する。判断できない項目は無理に修正せず、「確認待ち」に内容を残す。

レビューでは、文章や図がきれいに見えるかだけではなく、初めて仕様書を読む人が、追加説明なしで V2 を実装できるかを確認する。

### 1.1 確認対象

- `AssociationChart/GaiyouModuleV2.pu`
- `AssociationChart/DetailModuleV2.pu`
- `PAD/GaiyouPadV2.c`
- `PAD/DetailPadV2.c`
- `SequenceDiagram/sequenceV1.pu`
- `SequenceDiagram/sequenceV2.pu`
- 上記ファイルから生成した PNG および PDF

### 1.2 全担当共通のルール

- V0・V1 の章立てと文調を崩さない。
- V1 から変更していない部分は、理由を付けて残す。
- V2 で変更した部分は、本文と図の両方で確認できるようにする。
- 関数名、変数名、呼出し順序を本文と図で統一する。
- 実装結果や測定結果は書かず、正しい動作条件を書く。
- 修正後は、編集元と書き出し結果の両方を共有する。
