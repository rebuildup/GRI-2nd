# 1. 概要

## 1.1 製品の概要

本製品は、H8 マイコンに接続したモータ、LED、数値 LED およびスイッチを制御する。

製品 V1 では、LED の点滅判断および点灯・消灯処理を`ledexec()`が担当し、`main`関数のメインループから呼び出していた。この方式では、今後メインループ内の処理が増えた場合、LED 点滅の実行タイミングがメインループの実行周期に影響される可能性がある。

製品 V2 では、LED の点滅判断および点灯・消灯処理をタイマー割り込みから実行する。これにより、メインループの処理量に依存しない LED 点滅制御を実現する。

## 1.2 V2 の設計方針

V2 では次の変更を行う。

- `init_timer0()`の第 2 引数に`led_handler`を指定する。
- LED モジュール内の`ledexec()`を、同等の機能を持つ`led_handler()`へ名称変更する。
- LED の点滅判断および点灯・消灯を、タイマー割り込みから呼び出される`led_handler()`が担当するようにする。

## 1.3 V2 で変更しない事項

次の仕様は V1 から変更しない。

- マイコンと各装置の接続
- スイッチによる動作モードの切り替え
- モータの正転、逆転および停止
- エンコーダによる回転状態の取得
- 数値 LED への回転状態の表示
- 実行時引数による LED 制御パラメータの設定
- 点灯パターンの設定をアプリケーションで行う設計

# 2. 機能

![V2ユースケース図](Usecase/usecaseV2.png)

## 2.1 動作モードの切り替え

- P51 のプッシュスイッチを押すと、動作モードを ON にする。
- P50 のプッシュスイッチを押すと、動作モードを OFF にする。

## 2.2 動作モードが ON のときの動作

- トグルスイッチが ON、入力値が`0`のとき、モータを正転させる。
- トグルスイッチが OFF、入力値が`1`のとき、モータを逆転させる。

## 2.3 動作モードが OFF のときの動作

- モータを停止状態にする。

## 2.4 数値 LED

エンコーダの周期に応じてモータの回転状態を数値 LED に表示する。

- 正回転時は表示値をインクリメントする。
- 逆回転時は表示値をデクリメントする。

## 2.5 LED

LED は、実行時引数として与えられた次のパラメータに基づいて動作する。

| パラメータ             | 変数     | 内容                                            |
| ---------------------- | -------- | ----------------------------------------------- |
| 点滅周期               | `blmsec` | LED の点滅に使用する時間を指定する。            |
| 点滅の有無またはモード | `bflag`  | LED を点滅させるかどうかを指定する。            |
| 点灯パターン           | `num`    | 点灯対象とする LED のビットパターンを指定する。 |

### 2.5.1 点灯パターン

`main`関数は、`led(num)`を呼び出して LED の点灯パターンを設定する。

点灯パターンの設定はアプリケーションが担当する。現在は初期化後に`num`の値を変更しないが、今後、アプリケーションの実行状態を LED パターンで表示できるようにするため、`led(num)`はメインループ内に残す。

### 2.5.2 点滅判断および点灯・消灯

LED の点滅判断および点灯・消灯は、LED モジュールの`led_handler()`が担当する。

`led_handler()`は`main`関数から直接呼び出さず、タイマー 0 の割り込み処理から周期的に呼び出す。

### 2.5.3 既定の点滅動作

既定の LED 動作では、次の動作を繰り返す。

- 約 0.5 秒間点灯する。
- 約 0.5 秒間消灯する。
- 点灯開始から次の点灯開始までを約 1 秒とする。

### 2.5.4 実行時引数と LED 動作の関係

`main`関数は、実行時引数から`blmsec`、`bflag`および`num`を読み取る。

読み取った値は次の関数によって LED モジュールへ設定する。

```c
ledblinkmode(bflag);    /* 点滅モードの設定 */
ledblinktime(blmsec);  /* 点滅周期の設定 */
led(num);              /* 点灯パターンの設定 */
```

`led_handler()`は、これらの設定値に基づいて点滅判断および点灯・消灯を行う。

実行形式を次に示す。

```text
prog.elf [-Nzz] [-Fy] [-Bxxx] [-DEBUG1]
```

- `-Nzz`は LED の点灯パターンを指定する。省略時は`0x05`とする。bit4 の LED は点灯しない。
- `-Fy`は点滅モードを指定する。省略時は`1`とする。
- `-Bxxx`は点滅周期をミリ秒単位で指定する。省略時は`1000`とする。
- `-DEBUG1`はデバッグ表示を有効にする。省略時は無効とする。

点滅モードは V1 の仕様を引き継ぐ。

- モード`0`は、点滅周期に関係なく常時点灯する。
- モード`1`は、指定周期を 200 ミリ秒の倍数へ切り捨てて動作する。
- モード`2`とモード`3`は、V1 で定めた方法で指定周期を近似して動作する。近似方法は V1 の実装と一致させる。

本仕様書では、点灯を開始してから次に点灯を開始するまでを点滅周期とする。点灯状態と消灯状態を切り替える間隔は点滅周期の半分とする。既定値が 1000 ミリ秒の場合、500 ミリ秒点灯し、500 ミリ秒消灯する。

タイマー 0 の割り込み周期は 100 ミリ秒である。点灯状態と消灯状態は 100 ミリ秒単位で切り替わるため、点灯時間と消灯時間を合わせた点滅周期は 200 ミリ秒単位となる。モードごとの周期の近似方法は V1 から変更しない。

# 3. V1 から V2 への変更

## 3.1 変更前の V1

V1 では、`main`関数のメインループから`ledexec()`を呼び出していた。

```c
int main(int argc, char **argv)
{
    /* --------------------------------------------------------------------------------------------
       実行時引数の読み取り
       周期：blmsec
       モード：bflag
       パターン：num 
       コマンドライン因数から取得した値を使用し、LEDの点滅周期・点滅モード・点灯パターンを設定する。
    ------------------------------------------------------------------------------------------------*/

    ledblinkmode(bflag);
    /*LEDの点滅モードを設定する
     bflagの値に応じて、LEDの点滅動作を切り替える
    */
    ledblinktime(blmsec);
    /*LEDの点滅周期を設定する
    　blmsecで指定された時間を点滅周期として設定する
    */


    /*----------------------
    タイマー0の初期化・起動
    -----------------------*/
    init_timer0(COUNT_100MSEC, NULL);
    /*タイマー0を100ミリ秒周期で初期化する
    コールバック関数は使用しないためNULLを使用する
    */
    start_timer0();
    /*タイマー0をスタートさせる
    */

    /*------------------------------------
    メインループ処理
    ---------------------------------------*/

    while (1) {
    /*
        led(num);
        ledexec();

        /* LED以外の処理 */
    }
}
```

## 3.2 変更後の V2

V2 では、`init_timer0()`の第 2 引数に`led_handler`を渡す。メインループから`ledexec()`を削除し、LED の点滅判断および点灯・消灯をタイマー割り込み側へ移す。

```c
int main(int argc, char **argv)
{
    /* 実行時引数の読み取り
       周期：blmsec
       モード：bflag
       パターン：num */

    ledblinkmode(bflag);
    /*LEDの点滅モードを設定*/
    ledblinktime(blmsec);
    /*LEDの点滅周期を設定*/
    init_timer0(COUNT_100MSEC, led_handler);
    /*タイマー0の初期化
    　100ミリ秒ごとにled_handler()を呼び出す*/

    start_timer0();
    /*タイマー0の処理を開始*/

    /*メインループ*/
    while (1) {
        led(num);
        /*LEDの点灯パターンを設定*/

        /*
         * ledexec()は呼び出さない。
         * 点滅判断および点灯・消灯は、タイマー割り込みから
         * 呼び出されるled_handler()が担当する。
         */

        /* LED以外の処理を実行 */
    }
}
```

## 3.3 変更内容の比較

| 項目                       | V1                             | V2                        |
| -------------------------- | ------------------------------ | ------------------------- |
| 点灯パターン設定           | `main`から`led(num)`を呼び出す | 変更なし                  |
| 点滅判断                   | `ledexec()`                    | `led_handler()`           |
| 点灯・消灯処理             | `ledexec()`                    | `led_handler()`           |
| LED 周期処理の呼出し元     | `main`のメインループ           | タイマー 0 の割り込み処理 |
| `init_timer0()`の第 2 引数 | `NULL`                         | `led_handler`             |
| `ledexec()`                | 使用する                       | 削除する                  |

## 3.4 タイマー割り込みの仕組み

タイマーモジュールは、`init_timer0()`の第 2 引数として受け取った関数ポインタを`timer0_handler_body`へ保存する。

```c
static void (*timer0_handler_body)(void);
/*タイマー割り込み時似実行する関数を保持するポインタ*/

void init_timer0(int compare, void (*timer_handler_body)(void))
{
    /*割り込み時実行する関数を登録*/
    timer0_handler_body = timer_handler_body;
    /* タイマー初期化処理 */
    set_handler(36, timer0_handler);
    /*タイマー0の割り込みハンドラを登録*/
}
```

8 ビットタイマー 0 のコンペアマッチ A イベントが発生すると、`timer0_handler()`が呼び出される。

```c
#pragma interrupt
static void timer0_handler(void)
{
    /*割り込み処理に必要なセグメントを読み込む*/
    load_segment(36);
    /*タイマー0の割り込み回数をカウント*/
    t0v.count++;
    /*登録された関数が存在するかを確認する*/
    if (timer0_handler_body != NULL) {
        /*登録された関数を呼び出す*/
        (*timer0_handler_body)();
    }
    /*タイマー0のコンペアマッチA割り込みをクリア*/
    TCSR0_8 &= ~0x40;
    /*割り込み処理を終了*/
    return;
}
```

V2 では次の初期化を行うため、`timer0_handler_body`は`led_handler`を指す。

```c
init_timer0(COUNT_100MSEC, led_handler);
```

したがって、LED 制御の呼出し順序は次のようになる。

```text
8ビットタイマー0のコンペアマッチAイベント
    ↓
timer0_handler()
    ↓
timer0_handler_bodyがNULLでないことを確認
    ↓
led_handler()
    ↓
点滅判断およびLEDの点灯・消灯
```

# 4. 接続

接続仕様は V1 から変更しない。

## 4.1 モータ

- PA4 に PWM SIG 端子を接続する。
- PA3 に IN1 を接続する。
- PA2 に IN2 を接続する。
- PA1 にエンコーダ B を接続する。
- PA0 にエンコーダ A を接続する。

## 4.2 LED および数値 LED

- PB0 から PB7 に LED 端子を接続する。
- P4 に number LED 端子を接続する。

## 4.3 スイッチ

- P53 に一番手前のトグルスイッチを接続する。
- P51 に一番手前のプッシュスイッチを接続する。
- P50 に手前から二番目のプッシュスイッチを接続する。

# 8. 関数仕様

## 8.1 `led_handler()`

### 宣言

```c
void led_handler(void);
```

### 機能

LED に設定された点滅周期、点滅の有無またはモード、および点灯パターンに基づき、LED の点滅判断と点灯・消灯を行う。

V1 の`ledexec()`と同等の機能を持つ。（関数名の変更）

### 引数

なし

### 戻り値

なし

### 呼出し元

タイマー 0 の割り込み処理から、登録済みの関数ポインタを介して呼び出される。

### 処理条件

- タイマー割り込みのたびに呼び出される。
- LED モジュールに設定済みの値を使用する。
- 指定された条件に従い、LED を点灯または消灯する。
- 割り込み処理から呼び出されるため、長時間を要する処理を行わない。

## 8.2 `led()`

### 宣言

```c
void led(int num);
```

### 機能

LED の点灯パターンを LED モジュールへ設定する。

### 呼出し元

`main`関数のメインループ。

### V2 での扱い

V1 から変更しない。将来、アプリケーションの実行状態に応じて点灯パターンを変更できるよう、メインループ内に残す。

## 8.3 `ledblinkmode()`

### 宣言

```c
void ledblinkmode(int mode);
```

### 機能

LED の点滅の有無または点滅モードを LED モジュールへ設定する。

### V2 での扱い

設定方法は V1 から変更しない。設定値は`led_handler()`が使用する。

## 8.4 `ledblinktime()`

### 宣言

```c
void ledblinktime(int blmsec);
```

### 機能

LED の点滅周期を LED モジュールへ設定する。

### V2 での扱い

設定方法は V1 から変更しない。設定値は`led_handler()`が使用する。

## 8.5 `ledexec()`

V1 の`ledexec()`は、処理内容を変更せず`led_handler()`へ名称変更する。V2 のソースコードに旧関数名を残さないことを確認するため、次の各箇所から`ledexec`を削除する。

- 関数宣言の`ledexec`を削除し、同じ宣言を`led_handler`の名称で記述する。
- 関数定義の`ledexec`を削除し、同じ関数本体を`led_handler`の名称で定義する。
- `main`関数から`ledexec()`の呼出しを削除する。
- V2 のソースコードに`ledexec`の宣言、定義および呼出しが残っていないことを確認する。

## 8.6 `init_timer0()`

### 宣言

```c
void init_timer0(int compare, void (*timer_handler_body)(void));
```

### 引数

| 引数                 | 内容                                                                              |
| -------------------- | --------------------------------------------------------------------------------- |
| `compare`            | タイマー 0 のコンペアマッチ値を指定する。V2 では`COUNT_100MSEC`を指定する。       |
| `timer_handler_body` | タイマー 0 の割り込み時に呼び出す関数を指定する。V2 では`led_handler`を指定する。 |

### V2 での使用方法

```c
init_timer0(COUNT_100MSEC, led_handler);
```

第 2 引数として`led_handler`を渡し、タイマー 0 の割り込み処理から呼び出される関数として登録する。

# 9. 実装時の要求事項

V1 から V2 への変更では、次の事項を満たすこと。

- LED モジュールの`ledexec()`を`led_handler()`へ名称変更し、関数本体の処理内容は変更しないこと。V2 のソースコードには旧関数名`ledexec`を残さないこと。
- `init_timer0(COUNT_100MSEC, led_handler)`によって、タイマー 0 の割り込み時に呼び出す関数として`led_handler`を登録すること。
- `main`関数のメインループから`ledexec()`の呼出しを削除し、`led(num)`の呼出しは残すこと。
- `led_handler()`は`main`関数から直接呼び出さず、タイマー 0 の割り込み処理から呼び出すこと。
- `led()`、`ledblinkmode()`および`ledblinktime()`の使用方法と、LED の点灯パターン、点滅モードおよび点滅周期の動作は V1 から変更しないこと。
